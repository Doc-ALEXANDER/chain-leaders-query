# 全国链主企业查询

全国「重点产业链链主」企业公开名单查询站点，纯静态网页（无数据库、无后端、无外部 API），数据截止 2026-10-30。

## 功能

- 按**省份、企业、产业链、城市、年度、政策、批次、认定状态、来源**筛选
- 关键词搜索（企业名 / 产业链 / 城市）
- 查看每个主体的分批次来源明细
- 导出 CSV
- 下载各省及全国 Excel（`downloads/` 目录）

## 文件结构

- `index.html` / `app.js` / `styles.css` — 页面与逻辑
- `data.js` — 公开数据（31 省 / 1152 主体 / 1414 条记录）
- `downloads/` — 全国及各省级 Excel、资料包压缩包

## 数据口径说明

- 公示、培育、历史认定与正式名单均保留原始状态，不混为一谈。
- 「国央企补充」条目不代表链主认定，仅作有据来源补充。
- 公开网页数据不包含本地证据文件路径。

## 更新

修改数据后，将最新文件放入仓库根目录并提交推送即可（保持 `index.html`、`data.js`、`downloads/` 等路径不变）。
